## 🌟 Key Highlights & Exclusive Capabilities

### 🎬 Unified Cinemeta & Media Catalog
- **Rich Metadata Discovery**: Real-time trending catalogs, high-res posters, episode guides, and IMDb integration.
- **Instant Search**: Lightning-fast query resolution across movies, series, and anime.

### ⚡ Embedded Local Torrent Gateway
- **Zero Cloud Buffer Wait**: Built-in background Node.js BitTorrent engine converting P2P torrents into direct local HTTP streams on-the-fly.
- **Sequential Downloading**: Streams video files piece-by-piece from start to finish with instant playback seeking.

### 🚀 Hardware-Accelerated Native VLC Player
- **Universal Codec Support**: Plays HLS, DASH, MKV, MP4, and HEVC without transcoding.
- **Track Selector**: On-the-fly multi-audio channel switching and embedded subtitle track injection.

### 📥 High-Speed Background Download Engine
- **Resumable Downloads**: Reliable chunk downloading with auto-retry and pause/resume support.
- **Battery & Network Guard**: Efficient background service prioritizing Wi-Fi transfers.
